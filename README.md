# navvis-ivion-spatial
Proof-of-work for NavVis IVION full-stack (Java 17 / Spring Boot 3 + TypeScript/React + PostgreSQL/H2). Indoor spatial POI sync: floorplan coordinate transform (scale/rotate/translate), radius/nearest search with deterministic ordering, Spring JDBC, MockMvc REST tests. Viewer `viewer/ivion-viewer.tsx` renders POIs onto SVG floorplan.
Tests: 14 passing (`mvn test`).
